# Faulk — releases

Ce dépôt ne contient que les versions publiées du **helper Faulk** (mode Boost) : installeurs et fichiers de mise à jour, attachés aux releases GitHub.

Le code source de Faulk n'est pas ici. Pour télécharger le helper, passe par **https://get.faulk.app** : ce domaine redirige vers la dernière version publiée, et c'est lui que le helper interroge pour se mettre à jour.

---
